# NovaDeck

**Offline Hardware Telemetry, Diagnostics, Storage Treemap & C++17 NDK Benchmark Suite for Android**  
*(Минималистичный брутальный пульт системной диагностики, карты памяти и нативного бенчмарка для Android, вдохновлённый StellarHub)*

---

## Скачать релиз APK (GitHub Releases)

> **Установка и обновление без сноса старой версии!** Все релизы подписываются единым ключом (`io.novadeck.control`), поэтому новая версия устанавливается **прямо поверх старой** с сохранением настроек и истории.

- **[Страница релизов GitHub Releases (`NovaDeck-release.apk` + SHA-256)](https://github.com/RoMaSHia/NovaDeck/releases)**
- **[Скачать последний релиз напрямую (`NovaDeck-release.apk`, ~2.3 МБ, arm64-v8a + armeabi-v7a)](https://github.com/RoMaSHia/NovaDeck/releases/latest/download/NovaDeck-release.apk)**
- **[Зеркало из репозитория (`dist/NovaDeck-release.apk`)](https://github.com/RoMaSHia/NovaDeck/raw/main/dist/NovaDeck-release.apk)**

### Компактное обновление в один тап (In-Place OTA Updater)
Нажмите значок версии **`v1.2.0 ↻`** в верхней панели или кнопку в меню **`ОПЦИИ / CONFIG`**: откроется компактное модальное окно, которое проверит последний релиз на GitHub, скачает APK и запустит установщик **прямо поверх текущей версии** без её удаления.

## Возможности (v1.2.0 — полный паритет со StellarHub)

1. **Навигация свайпами влево/вправо:** все главные модули и внутренние вкладки переключаются плавным свайпом (`HorizontalPager`).
2. **Пульт (Home) + Умный Оптимизатор и Советник:**
   - Полная диагностика устройства с вердиктом **«Что не так»** и **«Что сделать»** (нагрузка ОЗУ, автозагрузка, мусор, ненужные приложения, галочки отправки телеметрии, нагрев) + кнопка **«ОПТИМИЗИРОВАТЬ ВСЁ»** для мгновенной выгрузки фоновых процессов и очистки кэша.
   - Паспорт смартфона, кликабельные показатели **Right Now** и матрица **Компонентов**.
3. **Монитор (5 вкладок + `LIVE / ПАУЗА`):**
   - **CPU**, **GPU/Экран** (FPS через `Choreographer`), **ОЗУ/Процессы**, **Сеть/Пинг** (C++ TCP-пинг `1.1.1.1:443` / `8.8.8.8:53`), **Батарея**.
4. **Память (Storage Checker + Super Optimizer):**
   - Многопоточный C++17 сканер + MediaStore, интерактивная **Squarified Treemap**, **Папки**, **Крупные файлы**, **Дубликаты (FNV-1a)** и **Оптимизатор**.
5. **Приложения (5 вкладок):**
   - Реальные иконки, **Польз.**, **Системные**, **Автозагрузка** (`RECEIVE_BOOT_COMPLETED` + остановка в ОЗУ), **Ненужные по мнению телефона** (OEM-блоат, давно не используемые, рекламные трекеры в автозапуске), **Остатки/APK**, экспорт и шаринг APK.
6. **Тесты железа и датчиков (4 вкладки):**
   - Битые пиксели, градиент/OLED, 120 Гц движение, 10-точечный мультитач с замером Гц, противофаза/свип/белый шум, микрофон, вибро, фонарик, тест кнопок и геймпада, `Camera2`, 6 датчиков 60 Гц + барометр.
7. **Защита и Приватность (4 вкладки):**
   - **Система** (шифрование, Root/Magisk, SELinux, ADB, VPN, Proxy, User CA), **Открытые порты** (`/proc/net/*`), **Отправка данных** (аудит галочек фонового сканирования Wi-Fi/BLE, отправки диагностики, читателей уведомлений/экрана, трекеров `AD_ID` и OEM-аналитики) и **Права**.
8. **Бенчмарк и троттлинг (3 вкладки):**
   - C++17 ALU, NEON FMA, SHA-256, LZ-сжатие, RAM Read/Write/Copy GB/s, латентность DRAM, Storage I/O, сравнение с SoC и 15с/30с/60с троттлинг-стресс тест.
