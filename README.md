# NovaDeck

**Offline Hardware Telemetry, Diagnostics, Storage Treemap & C++17 NDK Benchmark Suite for Android**  
*(Минималистичный брутальный пульт системной диагностики, карты памяти и нативного бенчмарка для Android, вдохновлённый StellarHub)*

---

## Скачать релиз APK (GitHub Releases)

> **Установка и обновление без сноса старой версии!** Все релизы подписываются единым ключом (`io.novadeck.control`), поэтому новая версия устанавливается **прямо поверх старой** с сохранением настроек и истории.

- **[Страница релизов GitHub Releases (`NovaDeck-release.apk` + SHA-256)](https://github.com/RoMaSHia/NovaDeck/releases)**
- **[Скачать последний релиз напрямую (`NovaDeck-release.apk`, ~2.3 МБ, arm64-v8a + armeabi-v7a)](https://github.com/RoMaSHia/NovaDeck/releases/latest/download/NovaDeck-release.apk)**
- **[Зеркало из репозитория (`dist/NovaDeck-release.apk`)](https://github.com/RoMaSHia/NovaDeck/raw/main/dist/NovaDeck-release.apk)**

### Компактное обновление в один тап (In-Place OTA Updater)
Нажмите значок версии **`v1.1.0 ↻`** в верхней панели или кнопку в меню **`ОПЦИИ / CONFIG`**: откроется компактное модальное окно, которое проверит последний релиз на GitHub, скачает APK и запустит установщик **прямо поверх текущей версии** без её удаления.

## Возможности (по модулям StellarHub)

1. **Пульт (Home):**
   - Паспорт смартфона (модель, SoC, ABI, ядро Linux, аптайм, индекс состояния).
   - Живые кликабельные показатели (**Right Now**): загрузка CPU, память ОЗУ, батарея, накопитель, частота экрана (Hz) и скорость сети — нажатие открывает нужную вкладку Монитора.
   - Интерактивная матрица **Компоненты** (`CPU`, `GPU/DISP`, `MEMORY`, `STORAGE`, `BATTERY`, `BUS/RADIO`) с детальным паспортом по тапу и блок **На проверку (To Review)**.
2. **Монитор (5 вкладок + кнопка `LIVE / ПАУЗА`):**
   - **CPU:** частоты и нагрузка каждого ядра, `/proc/loadavg` (`1m/5m/15m`), активные потоки ядра.
   - **GPU/Экран:** живой счётчик `FPS` и времени кадра (`ms`) через `Choreographer`, режимы герцовки (`60/90/120 Гц`), DPI, OpenGL ES / Vulkan.
   - **ОЗУ/Процессы:** ОЗУ + ZRAM/Swap, Heap и список активных процессов.
   - **Сеть/Пинг:** RX/TX график, IP, Wi-Fi RSSI / скорость / частота, и нативный C++ **TCP-пинг** (`1.1.1.1:443`, `8.8.8.8:53` min/avg/jitter ms).
   - **Батарея:** ток (мА), напряжение (мВ), мощность (Вт), ёмкость заряда (мАч), температура, здоровье и химия.
3. **Память (Storage Checker + Super Optimizer):**
   - Многопоточный C++17 сканер + MediaStore, интерактивная **карта памяти (Squarified Treemap)**, вкладки **Папки**, **Крупные файлы**, **Дубликаты (FNV-1a 64-bit)** и **Оптимизатор** (кэш, `.tmp/.log`, `.thumbnails`, лишние копии дубликатов).
4. **Приложения (App Manager):**
   - Реальные иконки приложений, пользовательские / системные пакеты, вкладка **Остатки и APK**, пакетное удаление, быстрый переход в кэш, экспорт в `Downloads/NovaDeck_Backups/`, шаринг APK и детальный инспектор (версия, min/target SDK, даты, разрешения).
5. **Тесты железа и датчиков (4 вкладки):**
   - **Экран:** битые пиксели, градиент и тест OLED-чёрного, тест плавности 120 Гц, 10-точечный мультитач с замером частоты опроса тача (Гц).
   - **Звук/Микр:** левый/правый/стерео/противофаза, логарифмический свип 20 Гц–16 кГц, белый шум, живой анализатор микрофона (дБFS), вибромотор, фонарик.
   - **Кнопки:** тест аппаратных клавиш, D-Pad и геймпада (keyCode / scanCode).
   - **Камера/Датчики:** инвентаризация всех модулей `Camera2` (Мп, размер сенсора, диафрагма, фокусные, OIS, RAW), 60 Гц осциллографы 6 датчиков (включая барометр) и полный список всех сенсоров устройства.
6. **Защита и приватность (3 вкладки):**
   - **Система:** шифрование, Root/Magisk/SU (C++), режим **SELinux**, ADB / Wireless ADB, блокировка экрана, VPN / HTTP Proxy, пользовательские CA-сертификаты, патч безопасности.
   - **Открытые порты:** таблица активных TCP/UDP сокетов из `/proc/net/*`.
   - **Права:** аудит доступа к камере, микрофону, геолокации, СМС, показу поверх окон и установке APK.
7. **Бенчмарк и троттлинг (3 вкладки):**
   - Полный нативный C++ набор тестов: **Integer ALU**, **ARM NEON FMA**, **SHA-256**, **LZ-сжатие**, **скорость ОЗУ (Read/Write/Copy GB/s)**, **латентность DRAM (ns)**, **скорость накопителя (SEQ + 4K IOPS)** и сравнение с эталонными SoC.
   - **Троттлинг-тест (15с / 30с / 60с)** с двухлучевым графиком падения производительности и нагрева, плюс сохранение истории замеров.
